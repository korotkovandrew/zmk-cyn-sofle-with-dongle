# Конфиг ZMK для Sofle CYN 60 (версия с dongle)

Подходит под nRF52840 nice!nano или аналогичный контроллер.

Рекомендуется редактирование с помощью `https://nickcoutsos.github.io/keymap-editor/`.

Dongle мод подразумевает промежуточное третье устройство помимо половин клавиатуры, подключающееся к ПК по USB.
